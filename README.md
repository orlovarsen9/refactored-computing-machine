# Проект CRM v26 — автоматическое создание листов

Исправлена важная вещь: в v25 открытие URL /exec ничего не создавало, потому что doGet только возвращал статус сервиса.

В v26:
- открытие /exec автоматически инициализирует CRM;
- создаются/обновляются листы: Пользователи, Проекты, Блоки, Комментарии;
- создаётся скрытый CRM_DATA;
- добавлена функция setupCRM(), которую можно один раз запустить вручную из Apps Script;
- если скрипт не привязан к нужной таблице, будет понятная ошибка.

Что сделать:
1. В НУЖНОЙ Google Таблице: Расширения → Apps Script.
2. Полностью заменить код файлом google_apps_script_backend.gs из v26.
3. Сохранить.
4. Deploy → Manage deployments → Edit → New version → Deploy.
5. Открыть ваш URL /exec в браузере.
6. Должен появиться JSON с `"initialized":true`.
7. Вернуться в Google Таблицу и обновить страницу — появятся листы Пользователи, Проекты, Блоки, Комментарии.

Если хотите, вместо пункта 5 можно в редакторе Apps Script выбрать функцию setupCRM и нажать Run.
